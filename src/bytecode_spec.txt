Disassembled instructions:

Integer ops (11):

add     a0 = a0 + a1
sub     a0 = a0 - a1
mul     a0 = a0 * a1
div     a0 = a0 / a1
mod     a0 = a0 % a1
xor     a0 = a0 ^ a1
or      a0 = a0 | a1
not     a0 = ~a0
and     a0 = a0 & a1
lsh     a0 = a0 << a1
rsh     a0 = a0 >> a1

Immediate ops (4):

Load immediate, or bitshift then load immediate
li0     a0 = imm
li1     a1 = imm
li0s    a0 = (a0 << 8) + imm
li1s    a1 = (a1 << 8) + imm

Load / store ops (9):

Load value relative to frame pointer
lf0     a0 = stack[fp + imm]
lf1     a1 = stack[fp + imm]

Restore frame pointer and return address
rest    ra = stack[fp]; fp = stack[fp + 1]

Increment frame pointer
ifp     fp += imm

Or from bottom of stack (globals)
lg0     a0 = stack[imm]
lg1     a1 = stack[imm]

Similar for store ops
sf      stack[fp + imm] = a0
sg      stack[imm] = a0
sra     stack[fp + imm] = ip + 1
sfp     stack[fp + imm] = fp

GC (4):
ireff   stack[fp + imm]->ref_count++
dreff   stack[fp + imm]->ref_count--
irefg   stack[imm]->ref_count++
drefg   stack[imm]->ref_count--

Branch ops (4):

Will check if MSB is 1, if so then make negative int32
Likely will have jumps > 1000 instructions for large conditionals, so add argument
+/- 8 million should be fine though

beq     if (a0 == a1) ip += (imm << 16) + arg
bne     if (a0 != a1) ip += (imm << 16) + arg
blt     if (a0 < a1)  ip += (imm << 16) + arg
bge     if (a0 >= a1) ip += (imm << 16) + arg

Jumps (1):

jmp     ip = a0

C / C++ calls (1):

stores returned values at stack[fp], callee must restore frame pointer
store function pointer in a0
argument count implicit - C programmer responsible for pulling array values in domain of # of passed args

call    stack[fp] = c_func(FriedeVM* vm)
